| 层级          | 推荐选择                        | 核心用途               |
| ----------- | --------------------------- | ------------------ |
| **后端框架**    | **Gin**                     | HTTP API、路由、中间件    |
| **数据库/ORM** | **GORM + PostgreSQL**       | 数据建模、增删改查、自动迁移     |
| **缓存**      | **Redis (go-redis/v9)**     | 会话缓存、限流、防重放        |
| **对象存储**    | **MinIO (minio-go/v7)**     | 图片、文件、附件           |
| **前端框架**    | **Vue 3 + TypeScript**      | UI 交互、组件化          |
| **前端构建**    | **Vite**                    | 开发服务器、打包           |
| **状态管理**    | **Pinia**                   | 全局状态管理             |
| **管理后台 UI** | **Element Plus**            | 后台管理界面组件库          |
| **跨端/小程序**  | **Uni-app**                 | 一套代码编译到小程序、H5、App  |
| **鉴权**      | **JWT**                     | 接口鉴权、会话管理          |
| **反向代理**    | **Nginx**                   | 静态资源托管、API 转发      |
| **容器化**     | **Docker + Docker Compose** | 服务编排、一键部署          |
| **数据库持久化**  | **Docker Volume**           | 数据持久化              |
| **API 调试**  | **Apifox / Postman**        | 前后端联调              |
| **代码管理**    | **Git + GitHub/GitLab**     | 版本控制、协作开发          |
| **分支策略**    | **GitHub Flow**             | 分支管理               |
| **提交规范**    | **Conventional Commits**    | 提交信息规范             |
| **CI/CD**   | **GitHub Actions**          | 自动构建、测试、推送镜像       |
| **镜像仓库**    | **Harbor**                  | 存储、扫描、分发 Docker 镜像 |
| **镜像构建**    | **多阶段 Dockerfile**          | 构建后端/前端镜像          |
